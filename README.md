# E_Commerce_Automation_Testing

This project demonstrates how to automate drag-and-drop functionality using **Selenium WebDriver with Java**.

## Automation Flow

1. Launch the browser.
2. Open the Drag and Drop webpage.
3. Locate the source element.
4. Locate the target element.
5. Perform the drag-and-drop action.
6. Verify that the element was successfully dropped.
7. Close the browser.

## Technologies Used

* Java
* Selenium WebDriver
* Chrome Browser
* Selenium Actions Class
